# Data

OHLCV exports for the Python backtester. The backtester needs the **base/entry
timeframe** (default 5m) as a CSV; it resamples 15m/45m internally using
confirmed bars only.

## Accepted CSV formats

| Source | Columns (any case) | Time format |
|---|---|---|
| TradingView (export chart data) | `Date, Time, Open, High, Low, Close, Volume` | `2026-01-05` + `14:30:00` |
| TradingView (single column) | `Date, Open, High, Low, Close, Volume` | ISO `2026-01-05 14:30:00` |
| KuCoin / exchange klines | `time, open, high, low, close, volume` | epoch ms (or s) |

All times are treated as UTC. Extra columns are ignored.

## TradingView export

1. Open the 5m chart for the symbol you care about (e.g. NEARUSDT.P on
   KuCoin, or NEAR-USDT perp).
2. Toolbar → **Export chart data** → CSV.
3. Make sure the range covers well over your intended study window —
   the 200-EMA warmup needs ~1500+ bars of headroom before signals matter.

## KuCoin export (public, no keys needed for candles)

```
GET https://api.kucoin.com/api/v1/market/candles?type=5min&symbol=NEAR-USDT&startAt=<ms>&endAt=<ms>
```

Pages of 1500 bars max — loop with `startAt` until you cover the range, and
write rows as `time,open,high,low,close,volume` (KuCoin returns
`[time, open, close, high, low, volume, …]` — reorder to OHLCV if you save
raw). Only **completed** bars should be included.

## Synthetic sample

`sample_near_5m_synth.csv` (generated by
`python -m backtester.sample_data`) is a clearly **synthetic** series with
regime cycles — used to validate the pipeline end-to-end (all four regimes,
both modes, every exit type). It does **not** represent real NEAR price
action; never cite its metrics as performance evidence.

`.csv` files here are data artifacts: regenerate or re-export as needed; they
are intentionally small enough to keep in git for reproducibility of tests.

## Real NEAR data (validation cycle)

For the real-data validation cycle (`docs/NEXT_STEPS.md`):

- **NEARUSDT.P 5m**, TradingView "Export chart data" CSV, range
  **2026-06-15 → 2026-10-11 UTC** (≈32k bars, includes the Oct 8–9 crash +
  recovery), saved as `data/near_5m_real.csv`.
- Real exports are **git-ignored** (`data/*_real*.csv`) — they stay local.
- Validate before anything else:
  `python -m backtester.check_data --csv data/near_5m_real.csv --window 2026-10-08,2026-10-10`

KuCoin's public candles endpoint (used if TradingView export is
inconvenient) only returns ~a limited history window and this sandbox
cannot reach it — a TradingView export is the canonical source for this
cycle, because the TradingView-vs-Python comparison must use one feed.
